# Post draft

New preprint: **Continuation Geometry Resolves Apparent Branch Splitting in
Unequal-Mass Three-Body Orbits**.

The Li-Li-Liao data set contains 135,445 unequal-mass planar three-body
periodic-orbit samples. A later analysis identified two branches in a
scale-invariant period-angular-momentum diagram. Direct continuation connects
those branches within one sampled component; a singular locus of the projection
explains their apparent separation.

The same continuation component contains two distinct planar Floquet stability
mechanisms: a +1 transition and an opposite-Krein Hamiltonian-Hopf transition,
independently reproduced in 60-digit arithmetic.
